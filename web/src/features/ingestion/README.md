Componentes de captação e leitura das fontes brutas ficam neste domínio.
`DemandSourceEvidence` é usado pelo detalhe da demanda para abrir uma citação
selecionada: mostra a fonte integral, realça o intervalo original devolvido pelo
pipeline-service e apresenta os segmentos imediatamente anterior e seguinte.
Os links carregam a localização da revisão no estado do roteador, incluindo a
query da execução acompanhada, para que o retorno preserve a revisão.

Segmentos sem offsets válidos são exibidos sem destaque automático e com aviso,
em vez de realçar um trecho incorreto.
