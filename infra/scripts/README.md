# Scripts de desenvolvimento

Utilitários de apoio ao time. Nada aqui roda em produção.

Scripts previstos:

| Script | Função |
|---|---|
| `bootstrap` | Verifica pré-requisitos (Docker, Python 3.12, Node 20), cria o `.env` e instala dependências. |
| `seed` | Popula o banco local com dados fictícios de cliente e demanda para desenvolvimento e demonstração. |
| `reset-db` | Derruba e recria o banco local, reaplicando as migrations. |

> Dados de semente são **fictícios**. Dado real de cliente nunca entra no repositório (RNF10).
